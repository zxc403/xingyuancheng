# 星渊城 XingYuanCheng v6.1

赛博朋克风格 3D 城市探索游戏（WebGL · Three.js · PBR · Bloom · SSAO · 真实 IBL 环境光）。

## 玩法

- WASD 移动（手机：左屏摇杆 / 右屏视角）
- F 上车 / 下车
- E 对话 / 军火
- 鼠标视角
- T 接任务

## 真实资产

- 4 套 Poly Haven PBR 纹理（沥青 / 森林 / 木地板 / 岩石）
- 1 个真实 HDR 环境光（drackenstein_quarry）
- Three.js + 全部 addons 本地化（无需翻墙）

## 技术

- Three.js r160（本地化）
- MeshPhysicalMaterial 完整 PBR
- PMREMGenerator + IBL
- UnrealBloomPass + SSAOPass + SMAAPass
- PCFSoftShadowMap 4096
- 5 灯系统（Ambient + Hemi + Key + Fill + Rim）
- 移动端自适应（高端机全开）
